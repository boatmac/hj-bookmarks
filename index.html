使用指南

帮助与使用说明

快速开始
  1. 点击“添加书签”保存第一条链接。
  2. 用文件夹和标签整理内容，使用顶部搜索快速查找。
  3. 数据默认保存在当前浏览器，请尽早配置自动备份。

按 Ctrl/⌘ + K 可以随时聚焦搜索框。

整理书签
  • 新建文件夹后，可拖拽书签或文件夹调整位置。
  • 点击星标加入收藏；点击标签可快速筛选。
  • 删除项目会进入回收站，文件夹的后代会一起保留。
备份与恢复
  • 在“备份/同步”中选择自动本地备份，并授权一个目录。
  • 最新备份和历史快照会自动写入所选目录，也可选择使用独立口令加密。
  • “从备份恢复”会先比较快照与当前数据，可安全合并、选择部分项目或完整替换。
  • 回收站保留删除项目 30 天，支持单项和批量恢复。
  • 手动导出的 JSON 是明文完整备份；浏览器 HTML 用于与浏览器迁移。
  • 每次目录备份写入后都会重新读取验证，也可在设置中随时检查备份健康状态。
  • 更换备份口令时可只影响新备份，或安全地重新加密当前口令可读取的历史。
多设备同步
  • 使用远端同步时，应用会自动选择兼容的连接方式。
  • 本地同步目录模式适用于 OneDrive、Google Drive、Dropbox 和 Syncthing 桌面客户端。
  • 所有设备必须使用完全相同的加密口令。
  • 同步设置和自动备份相互独立，建议同时启用。
  • 顶部快捷按钮可立即同步、重试、解锁或进入冲突中心。
处理冲突

应用会自动合并不同字段的修改。双方同时修改同一字段，或一端删除而另一端编辑时，会显示冲突中心；可保留本机、保留远端、逐字段选择或保留两个副本。

隐私与安全
  • 未配置同步时，书签不会离开当前浏览器。
  • 远端同步始终加密；本地自动备份可选择加密。
  • 同步和备份加密口令都无法找回；遗失后无法解密对应文件。
  • 共享设备上不要开启“刷新时保留凭据”。
